# Project Context (keep < 100 lines; update after each milestone)

**Project:** Secure Document Request and Approval Workflow (SDG 16). Academic MVP.
**Goal:** Student requests document -> Clerk reviews -> HOD approves/rejects -> Clerk uploads -> Student downloads. RBAC + audit log.

## Stack
HTML/CSS/vanilla JS (ES modules) · Node 24/Express 4 · MongoDB 7 (Docker single-node replica set) + Mongoose 9 · JWT HttpOnly cookie + bcryptjs · express-validator · Helmet · rate-limit · mongo-sanitize · Jest/Supertest. Production target: Render + MongoDB Atlas (prepared, NOT deployed).

## Architecture
client/ (static, served by Express, same origin) -> server/ (routes -> controllers -> services -> models) -> MongoDB + private upload folder (UPLOAD_DIR).

## Core files
- server/config/constants.js: roles, departments (CSE ME CIVIL ECE EEE), statuses, doc types, TRANSITIONS
- server/config/env.js (config + production guards), mongoUri.js (isLocalMongoUri), storage.js (upload folder check), transactions.js
- server/app.js (createApp, /healthz, trust proxy), server/server.js (boot, binds 0.0.0.0 in production)
- server/middleware/: authenticate, authorize, csrf, validate, upload, errorHandler
- server/services/: auth, user, request (scopeFilter), transition (atomic + audit in tx), document, audit
- scripts/: seedAdmin.js, seedDemo.js, verifyBuild.js, checkAtlas.js (npm run check:atlas)
- docs/: SRS, API, UML, TESTING, TRANSACTIONS, CI, DEPLOYMENT, DEMO, LIMITATIONS, SPRINT_PLAN, BACKLOG, screenshots
- Rules: AGENTS.md, CLAUDE.md

## Key decisions
Clerk + HOD department-scoped · atomic findOneAndUpdate transitions · isActive checked every request · cookie auth + custom-header CSRF · local Docker MongoDB bound to 127.0.0.1 (no auth) · tests only against a LOCAL MongoDB (they drop it) · production DB = Atlas via MONGODB_URI in Render.
