# Screenshots

Genuine captures of the running application, taken in the Claude desktop app's built-in browser pane (about 750 px wide, so the compact navigation shows) plus one at phone width (375 px). They show demo data created by `npm run seed:demo` (accounts ending in `.demo@example.com`). Demo data was removed afterwards. Screens that would have shown other real accounts were left out.

| `04-student-requests-all-statuses.jpg` | Student dashboard: one request in each status (Under review, Approved, Fulfilled with download) |
| `05-request-details-top.jpg` | Request details (Fulfilled) with the download button |
| `06-request-history-timeline.jpg` | Request history: Pending, Under review, Approved, Fulfilled, each with the actor |

| `08-hod-reject-reason.jpg` | HOD dashboard: Approve / Reject with the mandatory reason form |
| `09-admin-audit-log.jpg` | Admin audit log filtered to "request rejected" |
| `10-login-deactivated.jpg` | Login page after an admin deactivates a signed-in user |
| `11-admin-create-staff.jpg` | Admin: create staff account |
| `12-mobile-student-requests.jpg` | Student dashboard at phone width, including a rejection reason |
